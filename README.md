# powers

<!-- badges: start -->

<!-- badges: end -->

The goal of powers is to enable users to easily calculate common powers
of numeric data

## Installation

Package installation can be done directly by calling:

``` r
devtools::install_github("grcetmpk/powers")
```

## Example

This is a basic example which shows you how to use the `square` function
from the `powers` package.

``` r
library(powers)

# square a single numeric 
square(4)
#> [1] 16

# square a numeric vector
square(c(2,3,4))
#> [1]  4  9 16
```
